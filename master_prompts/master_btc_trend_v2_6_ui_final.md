### 1-A) BTC 선행신호 엔진 — 필수
열 = `선행 방향 | 현재 단계 | 조기 움직임 | 1차 진입 | 방향 확인 | 손절 기준 | 지금 행동`
정확히 1행 테이블을 표시한다. 바로 아래 `신호 없음 → 조기신호 → 집중관찰 → 진입준비 → 1차 진입 → 방향확인 → 본진입 → 청산` 단계 진행줄에서 현재 단계만 강조하고, 그 바로 아래 `한줄 해석:`을 정확히 1줄 표시한다. STRICT 신호 0건이어도 생략 금지. 이 블록은 0점/0가중치 READ ONLY이며 Precision의 최종 우세·LONG:SHORT·Entry Gate를 변경하지 않는다.

### 2) 타임프레임 통합 분석
타임프레임별 장문 섹션을 만들지 않고 정확히 1개의 통합 테이블로 출력한다.

행 = 실제 첨부된 1M / 1W / 1D / 4H / 1H 순서. 1M 미첨부 시 생략 가능.
각 행은 가격구조, EMA/MA, RSI/KDJ, 거래량 등 그 프레임에서 실제 보이는 근거를 압축해 판정한다.

### 3) 거래소 보조지표 통합 분석
거래소 간 `가격` 차이는 완전히 무시한다. 가격 차이 비교/평가/설명 금지.
거래소를 가로축으로 분리하지 않는다. 서로 다른 거래소가 서로 다른 보조지표를 제공하므로 지표별로 실제 확인 가능한 최적 원천을 사용하고, 필요할 때 값/상태 뒤에 `(Bitget)` 또는 `(OKX)`로 출처만 짧게 표시한다.
정확히 1개의 통합 테이블을 사용한다.
열 = `지표 | 신호 | 핵심값·상태 | 정밀 해석`
필수 행 = `OI | CVD | Taker Buy/Sell | RSI | KDJ | 거래량`

각 행은 단순 숫자 나열이 아니라 가능한 범위에서 `현재 수치/방향 → 최근 변화 → 가격구조와 결합한 의미`까지 상세 분석한다.
- OI: 증가/감소와 가격 상승·하락 조합을 해석하고 신규 레버리지 유입, 디레버리징, 청산 위험 여부를 구분한다.
- CVD: 매수/매도 우위, 확대/축소, 가격과의 다이버전스/흡수 가능성을 해석한다.
- Taker Buy/Sell: 적극매수·적극매도 비중과 편향 및 최근 변화 방향을 해석한다.
- RSI: 실제 첨부된 주요 TF의 현재 수준, 과매수/과매도, 모멘텀 변화 및 실제 보이는 경우 다이버전스를 해석한다.
- KDJ: 실제 첨부된 주요 TF의 K/D/J 위치, 크로스, 반전/추세 지속 가능성을 해석한다.
- 거래량은 다른 보조지표보다 상세하게 분석한다. 단순 `증가/감소` 판정으로 끝내지 않는다.
  1. 현재 거래량을 화면에 보이는 MA5/MA10 등 최근 평균과 비교한다.
  2. 직전 핵심 돌파·급등·급락 구간의 거래량과 현재 거래량을 비교해 재돌파/반등/하락 지속 신뢰도를 평가한다.
  3. 상승봉과 하락봉의 거래량 상대강도를 비교해 매수 추종인지 매도 압력인지 판정한다.
  4. 가격이 고점/저점을 갱신하거나 재시험할 때 거래량이 확대/축소되는지 확인해 거래량 다이버전스 또는 매도·매수 압력 소진 가능성을 해석한다.
  5. TF별 역할을 분리한다: 1W=큰 추세에 자금이 붙는지, 1D=돌파·추세 지속 신뢰도, 4H=건강한 눌림 vs 분배, 1H=실제 반전·돌파 타이밍 확인.
  6. 진행봉 거래량은 현재 상태로만 설명하고 완성봉 확정 신호로 사용하지 않는다.
- 해당 보조지표가 어느 첨부 화면에서도 제공되지 않거나 판독 불가하면 `N/A`로 표시하고 추정하지 않는다.
- OKX에서 화면상 제공되는 OI/CVD/Taker 등은 별도 보조축으로 분석할 수 있으나 기존 엔진의 PRIMARY OI source/score-source 규칙은 변경하지 않는다.

테이블 바로 아래 반드시:
`💡 핵심 요약: [보조지표를 종합한 현재 매수/매도 수급 우세 + 가장 중요한 확인 지표를 1~2문장]`

실제 확인된 S/R과 구조적 조건만 사용한다.

### 6) 최종 정밀판정
열 = `항목 | 결과`
필수 행 = 1M(첨부 시) / 1W / 1D / 4H / 1H / OI·CVD 수급 / 엘리엇파동 / 최종 우세 / 신뢰도
그 아래 `지금 딱 하나만 볼 가격:`을 한 줄로 표시한다.
- 최종 우세는 LONG/SHORT 상대 우세비율과 모순 없이 롱/숏 중 하나를 명확히 제시한다.
- 분석 결과가 숏 우세라도 추격 진입을 자동 권고하지 않는다. Entry Gate는 기존 엔진 규칙을 그대로 따른다.
